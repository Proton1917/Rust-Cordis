# 内核实现阶段与验收依据

上游基线为 `261c5fd`，论文规定模型，上游用例提供行为证据。内核阶段从空工程推进到能运行提供方和消费方的组件库。每项的实现位置及语义条款分别见[架构](02-architecture.md)与[一致性矩阵](04-conformance.md)。

| 历史阶段 | 核心行为 | 观察结果 |
|---|---|---|
| M0 | 固定工具链与工作区 | 内核和测试工具可分别构建 |
| M1 | 上下文视图与同步效应 | 登记和释放恢复先前环境，重复释放只产生一次效果 |
| M2 | 类型化事件 | 在回调中重入、增删监听器时派发次序符合约定 |
| M3 | 异步激活与清理 | 加载目标发生变化时，已登记的清理仍得到执行 |
| M4 | 服务出现、消失、替换 | 消费方按实际绑定激活，并在提供方退出前完成清理 |
| M5 | 拦截、调用方上下文、日志与定义替换 | 两个上下文可以访问不同的服务视图 |
| M6 | 完整组件示例、多线程运行 | 真实示例显示等待、激活、清理与重新绑定；并发操作最终收敛 |

编译器、工作区和模块布局可以演进。判断内核行为的依据是原有调用方能观察到的结果。运行时装载、宿主分组和交付工具的后续验收使用[运行时路线图](14-roadmap-phase2.md)。
