# ADR-0030 组合和原生替换的监管范围

M11 的宿主控制增加组合接口与原生换库。阶段预算调整为监管器目标 4500、上限 5500 代码行。

影响集合、候选版本与清理状态仍由监管器和内核各自拥有。网页通道和路由在后续阶段按独立职责提取。
