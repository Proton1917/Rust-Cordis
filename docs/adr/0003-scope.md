# ADR-0003 组件核心库的交付范围

第一阶段交付论文三层模型中的核心库。执行环境通过时钟与任务接口接入，加载器、文件监视、网络和应用功能在核心之外实现。

最初依据上游约 2057 行 TypeScript 设定内核 4000 行目标、6000 行上限。后续部署能力使用内核原语并由各自模块交付。
