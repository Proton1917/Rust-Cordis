# ADR-0028 内置接口数据类型的共享

| 项 | 内容 |
|---|---|
| 状态 | 已接受（2026-11-12） |
| 影响 | DOC-13 crate 划分、运行时只读接口；M11–M12 |

## 问题

内置 Runtime 接口的数据类型由原生 SDK 与核心共同使用。Q0 将核心依赖树与 SDK、ABI 分开，而 SDK 的最低 Rust 版本为 1.85，UP/1 实现使用工作区的 1.96。接口数据需要一个同时满足两方依赖边界的来源。

## 决定

新增 cordis-types，最低 Rust 版本为 1.85，仅依赖 serde，保存内置接口的数据结构。SDK、核心运行时和插件宿主按需使用。该 crate 使用安全 Rust，产品代码目标 200 行、上限 400 行。

RuntimeSnapshot 保留已定义字段，追加带 serde 默认值的进程分组、连接身份与已安装插件库存；接口次版本升为 1.1。libraries 保存宿主实际报告的数据，available_plugins 保存安装引用与探测元数据。两种记录具有各自的数据来源。

## 后果

核心通过 UP/1 提供数据，原生 SDK 复用相同的纯数据结构。服务实现与类型定义分别维护，库租约和状态字段来自真实宿主查询。
