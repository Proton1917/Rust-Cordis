# ADR-0012 原生库退役与映像回收

已停止调用的旧库仍可能留在进程地址空间。v1 用库租约覆盖代码和对象的使用期，默认 `unload = "never"`，旧映像随宿主退出回收。

当前源码在 `when-unleased` 模式下通过可选 C 入口 `void cordis_plugin_set_unload_v1(uint8_t wait)` 协调主动卸载。宿主在插件首次握手前调用一次。参数为 1 时，插件对描述符的成功释放须包括库级工作线程退出；为 0 时，宿主承诺保留映像。宿主在收到成功释放结果且租约归零后关闭支持该协议的库句柄。缺少此入口的旧插件仍可加载、替换，其退役映像保留至宿主退出。

旧映像数量超过配置阈值时执行有状态的组重启，默认阈值为 20。重启影响整个宿主，常规实例替换按真实依赖确定范围。
