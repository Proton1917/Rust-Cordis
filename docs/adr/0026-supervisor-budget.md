# ADR-0026 早期监管器的规模与职责

M10 的监管器集中掌握连接、进程和加载代。结构与评审的判断以源码职责为依据，当时的目标为 3500 代码行、上限 4500 行。

后续组合与路由阶段调整了预算，架构规则沿用实际所有者划分。比较历史数字时应区分代码行与含注释的总行。
