# ADR-0031 部署变更的批次语义

同一文件观察窗口内的来源可共同形成一个批次。核心先计算最终配置，准备候选，再保存受影响实例的状态并按依赖顺序切换。成功后发布程序绑定，失败时尝试恢复原来源和状态。

v0.2.5 为受理结果写磁盘记录。主分支在内存中为每个调用方保留最近结果，同一标识沿用它；核心重启后 watch 按上限重提。手动换回上一版本和失败候选的事务恢复使用各自相应的状态。
