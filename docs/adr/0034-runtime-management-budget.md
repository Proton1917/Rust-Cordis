# ADR-0034 运行时的持久部署职责

配置调和、管理授权和已确认程序绑定由运行时协调。文件监视、代码生成以及终端呈现已各有执行者。

阶段性评审给 cordis-runtime 设置 4500 行目标、5500 行上限。公开的部署与状态查询使应用能按实例识别运行版本。
