# ADR-0056 类型化方法表的布局识别

旧消费方根据本地声明读取类型化方法槽。接口名、主版本和表长度相同，也可能对应不同的机器签名；旧检查在历史回归中导致过进程崩溃。

主分支 ABI 1.2 给新消费方提供方法布局摘要；布局匹配时走类型化调用，其他情况按方法名分派。旧调用方继续沿用其编译时规则。新一代 ABI 的目标是把业务方法顺序从机器调用约定中移出。
