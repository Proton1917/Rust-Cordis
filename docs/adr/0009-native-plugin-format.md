# ADR-0009 插件格式：原生动态库

| 项 | 内容 |
|---|---|
| 状态 | 已接受（2026-11-11） |
| 影响 | `DOC-10` §2、§4、`Q8`；`DOC-12` §10 `format` 字段；`DOC-13` §1 |

## 问题

核心编译成独立可执行文件，插件单独编译后交给核心装载（`DOC-10` §1）。需要决定插件编译成什么格式。

## 选项

| 选项 | 内容 | 代价 |
|---|---|---|
| A | WebAssembly 组件，核心内嵌 wasmtime | 跨插件调用需要经过接口描述与数据复制；插件访问系统能力受 WASI 限制；核心体积增加约 10–20 MB |
| B | 原生动态库，自定义稳定 C ABI | 无沙箱；旧库映像难以从内存移除；需要 `unsafe` 的 FFI 层 |
| C | 原生动态库，不做 ABI 稳定，直接传递 Rust 类型 | 核心与全部插件必须使用同一编译器版本与同一依赖版本，违反 `G7` |
| D | 子进程插件，进程间通信 | 每次服务调用都是一次进程间往返 |

## 判据

1. 插件可以使用任意 Rust 库，包括依赖操作系统接口的库（项目所有者的要求：所有 Rust 代码都以插件形式挂在核心上）。
2. 跨插件服务调用的开销接近普通函数调用。
3. 插件可以用不同于核心的编译器版本构建（`G7`）。
4. 插件可以在运行中替换。

## 决定

选 B。A 不满足判据 1、2；C 不满足判据 3；D 不满足判据 2。

## 后果

- 原生插件是可信代码（`Q8`），可信度由验证门与回滚提供。
- 物理卸载不作保证，见 `ADR-0012`。
- `DOC-12` 描述符保留 `format` 字段，A 或 D 可以作为第二种装载器在后续加入，复用同一套插件契约（`DOC-11`）。
