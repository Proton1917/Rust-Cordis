# ADR-0009 原生插件的发布格式

独立编译和运行中替换要求调用双方约定机器边界。历史方案选择平台动态库与稳定 C ABI，使不同编译器构建的插件可以被同一宿主接纳。

现有库在原生宿主中装入。新架构保留独立编译，把业务方法从机器槽位中移出，将分派交给固定调用入口。
