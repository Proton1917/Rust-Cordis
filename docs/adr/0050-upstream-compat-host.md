# ADR-0050 原版 JavaScript 插件兼容宿主提案

原版插件依赖 JS 对象、代理、模块缓存与同步入口。提案由 Node 兼容宿主表达语言行为，Rust 内核管理实例和生命周期。

此项仍待排期。原版组件语义可作为通用架构参照；原样运行既有 npm 插件还需要专门的语言兼容验证。
