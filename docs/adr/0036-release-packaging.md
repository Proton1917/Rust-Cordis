# ADR-0036 独立发布包与平台装配

应用包需要在新的安装目录启动。原生库从实际编译产物取得，核心与宿主来自选定运行时；签名发生在最终包内布局确定之后，验证凭据跟随签名后的实际内容。

源码和部署目录分离时，目标工具接收二者的位置。应用声明网页和其他业务资源，框架处理平台后缀、装配清单、相对路径和运行时版本。
