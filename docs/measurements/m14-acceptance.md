# M14 原生启动、替换与恢复

macOS Apple Silicon 测试机有 14 个逻辑处理器、48 GiB 内存。宿主与核心用 Rust 1.96.0，跨编译器消费方另用 Rust 1.85.0。压力和直接调用采用 release 构建。

| 操作 | 历史观察 |
|---|---|
| 启动八个库、挂载一百个实例 | 全部激活耗时 6139 ms。[启动](m14-startup.json) |
| 切换 KV 实现 | 数据交接后计数继续增长，失败候选恢复原版本，无关实例维持原纪元。[迁移](m14-kv-migration.json) |
| 八个线程持续读取并执行五十次替换 | 第 21、42 次触发组重启。受影响实例中位数 3、最大 4；停顿中位数 241 ms、最大 661 ms。[原生替换](m14-native-replacement.json) |
| 核心异常退出后从检查点启动 | launchd 场景中从进程终止到全部插件激活为 9938 ms。[恢复](m14-core-recovery.json) |
| 同组直接调用 | 基线中位数 19.66792 ns，受测版本 18.62083 ns。数据来自相同 provider 和 Rust 1.85 release 消费方。[原始样本](m14-direct-call.json) |

五十次替换前后，全部受测进程 RSS 从 19856 增至 25776 KiB，核心从 8080 增至 9472 KiB。两次重启时宿主 RSS 分别由 13664、13712 KiB 降至 5616、5632 KiB。RSS 是驻留页指标；进程合计包含共享页。完整管理调用中位数 260.5165 ms，计入确认和应答时间，因此和实例停顿的口径不同。
