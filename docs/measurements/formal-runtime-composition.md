## 持久化与跨模块组合

存储探针原样编译 24 个生产源码块，使用真实文件、目录、硬链接、改名和独占文件锁。六种完整部署情形产生 242 个部署 I/O 错误案例、242 个部署退出案例、234 个恢复及错误重试案例和 228 个恢复退出案例。470 次退出由新进程执行恢复；退出路径直接终止进程并保留文件系统，停止前执行析构的路径与之分开。目录初始化另执行成功和八个同步位置的失败重试，共九个案例。

实际提交入口从同一份 `PreparedDeployment` 取得备份键和写入内容。源码证书据此建立备份覆盖条件，Lean 再证明日志保存原字节、任意 I/O 前缀投影可达，以及实际日志重放得到完整旧映像或新映像。恢复循环的结构证书覆盖任意合法名称，源码变异中遗漏 `z.state` 的路径同时被证书和执行检查发现。

`Composition` 实际构造非空路由批次，再分别表示取得首字节提交权、锁外调用 hook、取消、回退和资源析构。真实跨 crate 回归验证首次写入前取消回退、首次正字节写入后取消保留提交引用。全局存储结论通过事件投影调用实际构造日志的恢复定理。
