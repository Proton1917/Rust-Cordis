# M23 按名称调用与资源交接

同一 Rust 消费方分别连接同组原生、跨组原生、Python 和 TypeScript 提供方。各位置完成 KV 的 get、put、keys 和 flush，类型化与按名称调用得到一致的值。方法缺席、参数类型错误和缺少授权各按接口返回。[四类提供方](m23-matrix.json)

测试通过拥有型对象接收 1 MiB 字节流，逐字节读完后释放资源。提供方从内存实现切换到文件实现时，读操作继续取得正确结果；候选失败恢复后仍可读取。提供方卸载后，必需依赖进入等待。[替换与恢复](m23-lifecycle.json) · [脚本入口](m23-scripts.json)

提交前工作区有 339 项通过、1 项因固定 Git 修订对应旧 SDK 而失败。M23 提交后，对真实修订重新构建脚手架，目标用例通过，历时 19.31 秒。阶段的 340 项结果由这两部分构成。[固定修订测量](m23-pinned-git.json)
