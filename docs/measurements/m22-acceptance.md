# M22 HTTP、字节流与页面身份

Rust、Python 和 TypeScript 处理方实际收发 HTTP 方法、路径、查询串、重复头和正文。在每秒 50 次请求的窗口内执行三次替换和失败回滚，已登记的路径继续得到 HTTP 200；路由撤回后得到 404。处理错误、超时与进程退出分别产生相应的 HTTP 结果。[路由](m22-routes.json) · [生命周期](m22-lifecycle.json)

每种语言完成 64 MiB 上传和下载，比较完整字节一致；过大的已知长度或分块正文返回 413。该场景下 HTTP 进程的 RSS 增加 9,682,944 字节。中途关闭流会释放文件描述符。[文件传输](m22-files.json) · [通用资源流](m22-streams.json)

页面使用自己的连接身份读取页面属性，页面关闭时相应属性撤回。密钥服务根据后端调用实例的授权读取具体键。原始记录另覆盖网页外壳、SDK 字节编码及脚手架。[页面](m22-web.json) · [密钥](m22-secrets.json) · [字节表示](m22-bytes.json) · [脚手架](m22-scaffold.json)

RM-11 沿一条 HTTP/1.1 keep-alive 连接向每个处理方发送 10000 个小 GET，从发送到读完响应计时。[原始时延样本](m22-latency.json)

|---|---:|---:|---:|
| Rust | 10000 | 472.3125 | 611.750 |
| Python | 10000 | 401.0420 | 478.291 |
| TypeScript | 10000 | 348.3750 | 451.667 |
