## 组合验证结果

运行环境为 Linux x86_64、Rust/Cargo 1.96.0、Lean 4.19.0。原生组合夹具的使用方依仓库既有要求采用 Rust 1.85.0，提供方采用 1.96.0。Python 工具仅依赖标准库；代码规模分类另采用仓库计数器与 tree-sitter-rust 0.24.2。

| 范围 | 实际结果 |
|---|---|
| Lean 内核与公理审计 | 59 个定理通过；导入模块按 trust=0 检查；公理依赖限定为标准逻辑集合 |
| 生产生成与编译连接 | 204 个有限决策输入全部相同；惰性谓词读取次数同时核对 |
| 负控 | 错误 Lean 定理被拒绝；篡改 Rust 加载叶子后被编译执行核对拒绝 |
| 上游场景矩阵 | 177 条全部有归属：174 条适用、3 条既定语言特有范围；160 个独立 Rust 引用对应 181 项实际测试通过 |
| 矩阵之外的核心用例 | 44 项通过；2 项原有 release 性能测量维持显式 ignored |
| 监管器 | 库 3 项、真实 manager 流程 26 项通过 |
| 网页装配 | 3 项通过；两条 UP/1 提供方路径各回放 16 代 |
| 运行时 | 库 40 项、真实 offline 5 项通过 |
| 原生组件组合 | 同宿主和跨宿主 2 项通过；执行前后 451 个源文件摘要相同 |
| 证据工具 | 矩阵执行失败路径 8 项、证明失败证据 3 项通过 |
| 合计 | 304 项 Rust 测试通过，0 失败；11 项 Python 证据工具测试通过 |

同一套件只执行一次并复用其对多个矩阵条目的证据。核心、场景、监管器、网页与运行时的组合验证先完成；后续提交只增加交付文档和 CI，生产文件保持相同。组合 CI 分别保存形式化证据、矩阵结果和运行时真实测试输出，并对五个关键 offline 测试逐一要求实际 ok，名称缺失和零项执行使门禁失败。

## 证明与初始化义务

机器证明覆盖生命周期决策的全部输入分类、模型单步与无界轨迹、单效应清理所有权、准入守卫以及不可变视图缓存优化。实际生成的生命周期决策进入生产调用。Rust 字段适配、锁与引用计数、Future/回调、服务存储，以及 TypeScript 与 Rust 的整体操作语义映射仍具有独立精化义务，详见[形式化边界](../formal-semantics.md#实现精化义务)。这组结果建立了具体优化的证明和回归连接，完整框架的语言级等价仍需补齐这些映射。

持久发布以状态目录路径已持久存在、运行时独占其内容写入为前提。首次创建整条目录路径的确认仍属于初始化协议：同步全部祖先会改变仅可穿越目录的权限要求，逐层创建还需处理其他启动者提前观察目录的窗口。当前普通发布修复保留既有初始化与访问契约；目录内文件的确认、失败重试和缓存有效域已有实际回放。物理断电实验独立于本次故障注入证据。
