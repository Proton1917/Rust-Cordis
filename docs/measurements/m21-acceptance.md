# M21 三语言组合与应用交付

阶段验证让 Rust、Python 和 TypeScript 的 KV 服务接受同一契约，使用同一状态格式。实际进程完成六个方向的服务调用；持续计数中更换提供方语言时，消费方重新激活，核心 PID 保持。[跨语言调用](m21-language-cross.json) · [跨语言迁移](m21-language-migration.json)

网页场景检验两页独立上下文、后端撤回后的等待、重新提供后的恢复及全栈候选失败后的原状态。历史工作区执行有 325 个运行用例和 2 个文档用例通过。针对在全量负载下出现过的宿主时序问题，原生套件固定执行五轮，每轮 14 项通过。[并发负载记录](m21-native-stability.json)

发布验收使用包含解释器的实际包，验证 Python 与 Node 的依赖、符号链接、签名及包内启动。观测对象为当时的 ad-hoc tar。[脚本运行时](m21-script-runtimes.json)
