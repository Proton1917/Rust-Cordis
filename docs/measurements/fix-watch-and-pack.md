# 页面更新归属与发布路径

在 macOS arm64、Rust 1.96.0 下，页面投影依赖后端部署实例。修复后 watch 根据 `page_of` 提交真正的部署目标，两页草稿和应用外壳均在替换中保留。直接以页面投影作为目标的批次返回 code 4。新 watch 在旧版运行时等待所需的 1.4 接口。[页面投影记录](fix-watch-projections.json)

同一阶段检查了六个程序与库的签名、包内路径以及四个原生库的描述读取。Mach-O 的 `LC_ID_DYLIB` 使用相对安装名称，打包入口的默认路径检查能够报告带构建机路径的清单。早期两个发行版的装载命令另有原始结果。[发布修复测量](fix-pack-paths.json) · [历史装载命令观测](release-path-load-commands.json)

初次全量运行有三个与原夹具有关的失败，后续修正按受影响目标验证。合并当时有效结果共 343 项通过，固定 Git 脚手架采用推送后的既定修订。这些数据描述该发布修复的覆盖范围。
