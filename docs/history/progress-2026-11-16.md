# Rust-cordis 早期实现与发布记录

本页涵盖内核 M0 至部署版本 v0.2.5。各阶段的输入、测量口径和实现范围属于当时修订。版本之间的差异可由提交历史恢复；[85860d8 保存的逐阶段原始记录](https://github.com/Proton1917/Rust-Cordis/blob/85860d8b1fd784f6935084c611b07e12755cd7b8/docs/history/progress-2026-11-16.md)包含当时的失败、复核条件与数据。离线检出中也可用 `git show 85860d8:docs/history/progress-2026-11-16.md` 阅读。

## 从内核到原生宿主

M0–M6 完成上下文、服务、效应、事件、迁移与替换，M6 提交 `e459aa7`。上游 16 个 spec 的 177 条声明分别对应 Rust 行为或 JS 语言特例。[一致性矩阵](../04-conformance.md)

M7–M11 将同一组生命周期语义用于独立编译的插件。类型化和按名调用同时进入 v1，原生宿主承担库加载与执行；核心通过 UP/1 管理宿主和进程插件。M12（`6b4687f`）接入 watch 与持久化批次，M13 加入独立契约验证。M14 的 50 次原生替换中有两次宿主重启；其 RSS 与暂停时间按当时条件记录。[M14 测量](../measurements/m14-acceptance.md)

## 脚本、浏览器与对外接口

M15–M21 添加开发指南、打包、窗口、WIT 生成以及 Python、TypeScript 和浏览器 SDK。三语言 KV 用同一套状态格式演示跨语言替换。页面草稿和服务依赖在真实浏览器中检查；M21 首轮直接调用性能测量与并发复核负载重叠，另有一次协调停载测量，两份样本均保留。[三语言验收](../measurements/m21-acceptance.md) · [时延与负载](../measurements/m21-performance/README.md)

M22 添加 HTTP 路由、来源身份、密钥和字节流。M23 增加按运行时名称取得对象与方法的公开 SDK 能力。[HTTP 与流](../measurements/m22-acceptance.md) · [动态调用](../measurements/m23-acceptance.md)
