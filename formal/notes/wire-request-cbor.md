# UP byte grammar and complete request ownership

## Objects and proof statements

`WireSemantics` defines the published map-form UP envelope, nonzero u64 request identifiers, nonempty method names, nonzero u32 error codes, a four-byte big-endian frame header, and a stream of frames. The theorems quantify over arbitrary valid messages, frame bodies, unused suffixes, lists of frames and chunk partitions. Oversized headers reject before a body is required. The invocation-budget integer writer covers every u64 value, including the 23/24, 255/256, 65535/65536 and 32/64-bit width changes. Replacing the final budget field preserves the preceding message bytes and rebuilds the frame length.

The production request allocator starts at 1. Rust's `fetch_update` with `checked_add(1)` allocates the old frontier and moves to its successor; an exhausted frontier returns code 8 unchanged. Python and TypeScript use arbitrary-precision frontiers. The model proves increasing allocation and rejection at the bound. The compiled source probe exercises the final two successful boundaries and exhaustion.

The current protocol checks UP/1 and advertises `invoke_budget_v1`. The capability allows the caller to transmit a remaining invocation budget. There is no general version-range negotiation or same-connection reconnect transition in this implementation. Interface version selection and deployment process replacement have their own models.

`RequestSemantics` composes queue admission, first positive write, cancellation, write completion, response settlement and result return. A received payload has an owner during the interval between settlement and coroutine resumption. Every event trace conserves payloads across held, returned, abandoned and late-closed categories; every completed request removes its pending entry and holds no orphaned result. A successful return happens at most once. The shared session theorem proves FIFO decomposition, the unique first-write/rollback token and payload conservation over the same trace. Deadline inheritance is monotone through arbitrary nesting, and cancellation releases all held payloads along the supplied active descendant edges.

## Python settlement/cancellation fix

An asyncio Future can receive a payload immediately before its awaiting request task is cancelled. Removing the Future from the pending table then leaves the settled payload without a receiver. `Connection.request` now tracks the successful return separately from send completion. Its `finally` block closes a successful settled Future result when that result was not returned. Cancelled and failed Futures have no payload to close. Normal return transfers the payload to the caller. Late responses continue through the existing response-side close path.

The whole-method probe executes settlement followed by cancellation before task resumption, response followed by send failure, normal return and a response after cancellation. The regression suite also exercises actual streams, writer backpressure, deadline propagation and inbound cancellation. Removing the new cleanup from the source AST reproduces the leaked payload. The TypeScript probe executes the complete source `Connection` class after native TypeScript transformation; it includes the response-before-failed-send window, cancellation before and after write, timeout, already-cancelled calls, and response settlement before a later abort.

## CBOR values and normalization

`CborSemantics.Data` is a recursive CBOR data model. Text contains UTF-8 bytes checked by the Lean UTF-8 decoder. Maps preserve an ordered list of arbitrary keys and values, including duplicate keys. Floating values contain binary64 bit patterns, so mathematical NaN equality is not used to state a roundtrip.

`Parses` is an independent byte grammar. Integer and length headers include direct, 1-, 2-, 4- and 8-byte arguments; the grammar accepts overlong argument widths. It includes definite and indefinite arrays/maps, segmented byte/text strings, arbitrary tags, all three IEEE widths, booleans, null and undefined-to-null. Every text segment must be valid UTF-8. Reserved argument values and unsupported simple values have no grammar production. The encoder uses definite lengths and shortest integer arguments. `arbitrary_recursive_roundtrip` proves that every fitting recursive input is parsed with its unused suffix preserved. `recursive_short_float_roundtrip` uses the dependency's guarded float shortening recursively throughout the value graph.

The `FloatCodec` parameter records the fixed dependency's conversion and expansion operations. Both serialization layers check expanded-bit equality before choosing a narrower representation. The proof therefore covers every original binary64 pattern, including signed zero, infinities, subnormals and NaN payloads, for any conversion primitives satisfying their width types. The half/single/double byte productions and `actual_float_encoding_parses` connect that selection to the byte grammar. The source certificate reflects the guards from both `ciborium::Value::serialize` and `ciborium_ll::Header`.

Raw tag identity and numeric meaning are distinct for CBOR bignums. Ciborium interprets tags 2 and 3 with definite byte strings of at most 16 bytes as u128/i128 values. A negative magnitude at least 2^127 is rejected; longer strings remain tagged. The source certificate reflects the dispatch width, tag numbers and signed conversion. `every_u128_has_integer_roundtrip` and `every_negative_i128_has_integer_roundtrip` compose byte parsing with the integer interpretation, using legal fixed-width bignum bodies. Actual encoding can remove leading zero bytes while retaining the same integer. `encoded_tag_has_dependency_meaning` states the corresponding tag interpretation directly.

`MathValue` extends this connection to arbitrary finite mathematical trees. Integer leaves range from i128::MIN through u128::MAX; arrays, map keys, map values and ordinary tags contain the same recursive kind of tree. `lower` chooses a scalar encoding or a tag 2/3 bignum with leading zero bytes removed. `minimal128_preserves_magnitude` and `minimal128_length` prove that removal preserves the number and the 16-byte bound. `every_lowered_tree_preserves_meaning` gives an independent recursive `Denotes` relation to the original mathematical tree; `every_lowered_tree_fits` and `every_lowered_tree_is_normalized` prove encoding validity and a normalization fixed point. `recursive_integer_tree_roundtrip` composes these results with the byte grammar and resource policy, so nested large integer leaves have the same mathematical meanings after decoding. Ordinary tags 2/3 remain available around non-byte bodies and byte bodies longer than 16 bytes; shorter definite byte bodies are represented by their integer meanings. The production-codec regression nests u128::MAX, i128::MIN and leading-zero tag 2/3 bodies inside arrays, map keys/values and an ordinary tag.

The recursive normalization function runs before resource validation for generated definite-length encodings. Consequently, tag 60000 around tag 2 with byte body `[1]` becomes a valid reference to integer 1. Negative-bignum overflow in a map key propagates through the entire tree as rejection. Both compositions have explicit theorems and production-codec regressions. Ciborium retains tag 2/3 around an indefinite byte body as an ordinary tag; the byte grammar records this representation, and the normalized-encoding theorem is explicitly restricted to the definite-length encoder output.

Resource tag 60000 requires a positive u64 integer. Persistent data rejects this tag anywhere in the graph, including map keys and nested arrays. Collection length, container depth and node count are explicit graph policies. The source certificate checks the resource predicate for arbitrary tags and values; the actual codec probe also exercises malformed UTF-8, truncated input, trailing bytes, reserved/simple values, resource violations and capacity violations.

## Evidence and implementation boundary

`check_wire_semantics.py` extracts the restricted `integer_width` and `update_budget` bodies and the atomic allocator expression. The generated Lean certificates quantify integer width, appended integer bytes and allocator arithmetic. Truncation and frame-header statements pass a closed syntax check; the prefix and frame-replacement theorems assume a valid previous frame, offset and representable new length. The complete original Rust functions are separately compiled and executed, alongside the whole Python and TypeScript request paths. Width, CBOR-tag, allocator-increment and SDK cleanup mutations must fail.

`check_cbor_semantics.py` builds the actual `cordis-up` crate with the locked dependencies and links `cbor_probe.rs` against that build. Its source certificates cover the resource predicate, both float narrowing layers and bignum dispatch. Their source mutations must fail, as must an independently compiled resource-guard mutation. The finite public-codec corpus contains every value constructor, recursive trees, float bit patterns, duplicate map keys, valid special encodings, malformed encodings, limits and numeric-tag normalization. Each receipt records source hashes, dependency hashes, counts and named negative-control outcomes.

The grammar proof is a specification theorem. The entire ciborium byte parser, serde machinery, UTF-8 implementation, IEEE conversion primitives, allocator, language runtimes and compiler are dependency boundaries. The finite execution corpus and source-reflected subprogram certificates are recorded separately from the arbitrary-data and arbitrary-trace theorems. Python's cbor2 and TypeScript's cbor-x numeric representation policies remain language-specific codec contracts; the Rust bit-preservation theorem applies to the Rust/ciborium path. The whole-request proofs concern ownership and lifecycle rather than an assertion that all three language codecs preserve the same host-language object identity.
